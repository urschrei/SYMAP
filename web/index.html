SYMAP

The Synagraphic Mapping System

An implementation of SYMAP, the line-printer mapping program developed at the Harvard Laboratory for Computer Graphics and Spatial Analysis by Howard Fisher and Betty Benson, based on the 1971 manual. Decks can also be made from CSV, GeoJSON or TopoJSON files with Import data.

Card deck


        
      

      
 

      

        Card reference
        

          
Each line is an 80-column card. Tab moves to the next field (right-justifying a number you have just typed), Shift+Tab to the previous one, Esc leaves the editor. Locations are measured down from the top border and across from the left border.

          
Packages

          
A header card opens each package, 99999 in columns 1–5 closes it, and 999999 ends the deck. A package stays in effect for later maps until replaced; an empty package removes it.

          

            
PackageCards

            
              
A-OUTLINEOne vertex per card: down 11–20, across 21–30. Repeat the first vertex to close an outline; several outlines are allowed.

              
A-CONFORMOLINESFirst card of each zone: value reference 1–5 (blank: next), A, L or P in 10, first vertex 11–30. Further vertices with 1–10 blank; repeat the first to close an area.

              
B-DATA POINTSOne point per card: down 11–20, across 21–30.

              
C-OTOLEGENDSSymbol: strikes 6–9, P in 10, location 11–30, shift (lines, columns) 31–50. Text: length 4–5 (- in 1 to read down), P, location, shift; the text on the next card. Line or area: strikes 6–9, L or A, then one vertex per card.

              
D-BARRIERSOne vertex per card: down 11–20, across 21–30, strength 31–40 (-1. impermeable). Repeat the last vertex to end a barrier.

              
E-VALUESOne value per card in 11–20, in data point (or zone) order. A blank card is a blank value.

              
E1-VALUES INDEXReference 1–5, replacement 6–10 (blank: previous plus one).

              
F-MAPThree title cards, then electives.

            
          

          
Columns 31–40 and 41–50 of a header card (8. and 10.) switch that package to row-and-column measurement.

    Import data
    
      
    
      
    Points (CSV, GeoJSON or TopoJSON) or polygons (GeoJSON or TopoJSON)
        with a numeric value become ordinary cards, which you can then edit: polygons become
        zones whose shared borders are simplified together, and points become data points
        with an outline around them. Lines become line legends or barriers.
        More on importing.
